# Загрузка Datatour «Чёрная пятница 2026» в WordPress клиента

Комплект от 14 октября 2026 года. Исходники взяты из `milkinenpaul-arch/test`, ветка `main`, коммит `a68681823f4f86166deebcd2b1361607b81301e9`.

## Рекомендуемый способ: плагин через админку

Используйте **Datatour BF2026 Landing — Compatible**, версия **1.0.1**. Если прежний плагин **Datatour BF2026 Landing** уже установлен, деактивируйте его перед активацией версии Compatible. Исходный ZIP версии 1.0.0 сохранён в репозитории для истории; на старых версиях WordPress он не подходит для отдельного шаблона страницы. В версии 1.0.1 вызов `wp_body_open()` выполняется только при наличии этой функции.

1. Сделайте резервную копию сайта и сначала проверьте страницу на тестовой копии. Для установки нужны права администратора и разрешение на загрузку плагинов.
2. В WordPress откройте **Плагины → Добавить новый → Загрузить плагин**. Выберите `datatour-bf26-compatible.zip`, нажмите **Установить**, затем **Активировать**. Загружайте именно этот ZIP: архив исходников не является плагином.
3. Откройте **Страницы → Добавить новую**. Назовите её «Чёрная пятница 2026», задайте адрес `black-friday-2026`. Если страница с таким адресом уже есть, сохраните её копию и работайте с существующей страницей.
4. Добавьте один блок **Шорткод** с текстом `[datatour_bf26]`. В классическом редакторе WordPress 4.9 вставьте `[datatour_bf26]` в содержимое страницы на вкладке **Текст**; блоки Gutenberg там не требуются. Не добавляйте одновременно HTML из исходников и не вставляйте целый файл предпросмотра. В редакторе шорткод может отображаться только текстом; результат проверяйте через **Предпросмотр**.
5. В настройках страницы выберите шаблон **Datatour — отдельный лендинг**. Он выводит макет с его собственной шапкой и подвалом. Тема остального сайта остаётся активной. Если ваша тема или редактор не показывают этот шаблон, используйте их полноширинный / Canvas-шаблон без шапки, подвала и заголовка либо попросите администратора назначить шаблон страницы `datatour-bf26/landing.php`. При обычном шаблоне вокруг макета могут остаться элементы темы.
6. Сохраните страницу как черновик и откройте предпросмотр. Проверьте меню, фильтры, выбор отеля, обе формы и мобильную ширину. Очистите кеш WordPress и CDN, если используется кеширование. Исключите эту страницу из проблемных оптимизаций JavaScript только если они нарушают работу макета.
7. Замените демонстрационные тексты, контакты и фотографии, проверьте материалы и условия. Публикуйте страницу после согласования данных. Адрес будет `https://ваш-домен/black-friday-2026/`, если сайт использует обычные постоянные ссылки.

Плагин регистрирует шорткод и шаблон, подключает CSS/JavaScript страницы; он не создаёт страницу автоматически и не меняет активную тему. Для удаления макета уберите шорткод и смените шаблон страницы, затем деактивируйте плагин.

## Где редактировать

В архиве исходников лежат `datatour-bf26.html` (тексты и структура), `datatour-bf26.css` (оформление) и `datatour-bf26.js` (25 отелей, фотографии, фильтры и формы). В плагине они находятся в `wp-content/plugins/datatour-bf26-compatible/assets/`. Изменённые файлы можно загрузить по SFTP или через файловый менеджер хостинга; для следующей поставки безопаснее собрать обновлённый ZIP. После правок CSS/JS очистите кеш. Не редактируйте исходники на рабочем сайте без копии.

При этом способе лендинг хранится в файлах плагина: редактор WordPress показывает шорткод, а не отдельные блоки и карточки отелей. Редактирование отелей через поля админки потребует дополнительной интеграции.

Календарный таймер считает до **27 ноября 2026 года, 00:00 по Минску**; он не подтверждает сроки акции. Сроки акции `campaign.start` и `campaign.end` пока не заданы. Логотип встроен в HTML. Изображения, карточки и подписи демонстрационные; подтвердите их перед размещением на сайте клиента.

## Что работает и что требует подключения

В текущем комплекте: 15 блоков, 25 карточек, переключение лето/зима, выбор отеля и перенос в форму, локальная проверка ввода. Отправка заявок, CRM, Tourvisor и карта **не подключены**. Сообщение «Демонстрация: данные проверены, отправка ещё не подключена» означает только проверку ввода; заявка никуда не ушла. На боевом сайте сначала подключите реальный обработчик, политику обработки данных и подтверждённые контакты либо не публикуйте демонстрационные формы как рабочие.

Исходный самостоятельный предпросмотр проверен в Chromium: 15 блоков, 25 карточек, смена сезона, перенос отеля, ошибки и корректный ввод формы, отсутствие горизонтального переполнения на 360/768/1440 px и ошибок JavaScript. Версия Compatible 1.0.1 установлена и проверена на WordPress 4.9.8: отдельный шаблон, публичная страница и её CSS/JavaScript доступны. В браузере проверены карточки, фильтры, перенос отеля и демонстрационная форма на содержимом и ресурсах, полученных с сайта по HTTPS. Существующие сторонние скрипты сайта, использующие внешнюю библиотеку jQuery, не входят в проверку компонента: этот внешний домен недоступен в облачной тестовой среде. Для другого сайта совместимость с его темой и плагинами проверяйте на тестовой копии.

## Альтернатива без установки плагина

Архив `datatour-bf26-sources.zip` содержит HTML, CSS, JS, самостоятельный предпросмотр, лицензию, Blueprint и оригинальный README. Инструкция подключения через дочернюю тему находится в README: HTML вставляется в «Произвольный HTML», CSS и JS подключаются отдельно только на этой странице. Не используйте этот вариант одновременно с плагином.

## Обновления и Playground

WordPress клиента не синхронизируется с GitHub автоматически. Новые правки нужно заново переносить в файлы сайта или обновлять плагин из нового ZIP. Изменения на клиентском сайте также не возвращаются в GitHub.

Для отдельной демонстрации в WordPress Playground используйте **New → From a URL** и `https://raw.githubusercontent.com/milkinenpaul-arch/test/main/blueprint.json`. Это создаёт отдельный демонстрационный WordPress, а не обновляет сайт клиента. Уже открытый Playground не подхватывает новые коммиты автоматически.
