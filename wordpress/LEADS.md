# Заявки Datatour в WordPress

Откройте **Админка → Заявки Datatour → Открыть**.

Прямая ссылка: https://sales.datatour.by/wp-admin/admin.php?page=dtbf26-leads

Доступ есть только у администратора WordPress. В списке показаны дата по Минску,
имя, контакт, цель обращения и состояние email-уведомления. Внутри заявки доступны
все отправленные поля, выбранный отель, состав туристов, пожелания, источник и согласие.

Каждая новая валидная заявка сначала сохраняется в базе WordPress. Email отправляется
после сохранения, и его ошибка не отменяет принятую заявку. Статус «Передано серверу»
означает принятие письма почтовой функцией; он не подтверждает доставку в ящик.

Повторная отправка с тем же ID не создаёт вторую запись и не отправляет второе письмо.
Суточная очистка служебных ограничений не удаляет сами заявки. Записи закрыты от
публичного просмотра, поиска, REST API и стандартного экспорта WordPress.

Сохранение добавлено в версии 2.2.5. Содержимое заявок, отправленных до этого
обновления, автоматически восстановить нельзя: оно не сохранялось в базе.

Проверки: `php tests/forms.php` (включая сбой почты, отказ сохранения и права доступа)
и `node tests/frontend.cjs` с Playwright и Chromium. Эти тесты не отправляют реальные письма.
