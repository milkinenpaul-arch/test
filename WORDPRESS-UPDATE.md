## Установка, публикация и откат

Используется прежний `datatour-bf26-compatible`, страницаID287, URL, шорткод `[datatour_bf26]` и шаблон `datatour-bf26/landing.php`. Сервер клиента: WordPress 4.9.8 / PHP 5.4.45.

Перед последней правкой сохранена действующая версия 2.2.0; raw-содержимое трёх статей сохранено перед предыдущим большим пакетом, вне Git. Обновляющий помощник проверяет контрольные суммы, записывает ресурсы/обработчик в новую папку `assets/v2.2.1`, затем атомарно переключает главный PHP-файл. Прежние ресурсы остаются для отката. Административные ответы, cookies, пароли и резервные копии не входят в репозиторий.

Для возврата только последнего обновления предназначена кнопка **Roll back this Datatour update** последнего помощника `Datatour scoped update`: активировать только его, выполнить возврат, затем выключить. Это возвращает плагин к 2.2.0; содержимое статей при этом не меняется, для него сохранена отдельная резервная копия.

ZIP `downloads/datatour-bf26-2026-10-14/datatour-bf26-rollback-from-2.2.1.zip` предназначен для полного возврата к исходной реализации до задания. Он возвращает старый дизайн и демонстрационные формы, поэтому применять его следует только для такого возврата. После проверки вспомогательные плагины обновления/восстановления выключены; активным остаётся основной совместимый плагин. Собственная сессия автоматизации завершена, локальные cookies удалены.

Производственный ZIP: `downloads/datatour-bf26-2026-10-14/datatour-bf26-production-2.2.1.zip`. Для другого WordPress установите ZIP как плагин, создайте страницу с `[datatour_bf26]`, назначьте шаблон «Datatour — отдельный лендинг». Создайте три материала из `news-content.json` и задайте их местные ID/URL в конфигурации. Не включайте старый демоплагин одновременно с совместимым.
