# Данные Google-таблицы

Источник: https://docs.google.com/spreadsheets/d/1ojVZc3m0Xk0emdHye4zvwIBNUUkSA1O05xiHdQb424M/edit

По указанию пользователя синхронизируются **все табличные вкладки**.

После первого успешного запуска появятся:

- `workbook.json` — значения и формулы всех вкладок; этот файл можно редактировать в GitHub.
- `sync-state.json` — контрольные суммы последней подтверждённой синхронизации; вручную не редактировать.

Первое подключение только читает Google и создаёт снимок в GitHub. Сейчас данных таблицы в этой папке нет: реальное подключение ещё не авторизовано.

Значения хранятся с явным типом, чтобы сохранять ведущие нули и различать текст и формулы:

```json
{
  "spreadsheet_id": "1ojVZc3m0Xk0emdHye4zvwIBNUUkSA1O05xiHdQb424M",
  "sheets": [
    {
      "sheet_id": 0,
      "title": "Название из таблицы",
      "rows": [
        [{"stringValue": "Отель"}, {"stringValue": "Цена"}],
        [{"stringValue": "REGNUM"}, {"numberValue": 1200}],
        [null, {"formulaValue": "=B2*2"}]
      ]
    }
  ]
}
```

Это пример формата, не выгрузка пользовательской таблицы. Пустая ячейка — `null`, логическое значение — `{"boolValue": true}`. Даты в Sheets хранятся числовым значением; существующий формат даты остаётся в Google. Синхронизируются значения и формулы, а не форматирование/диаграммы/комментарии.

Инструкция активации и разрешения конфликтов: [Google Sheets ↔ GitHub](../../integrations/google-sheets/README.md).
