# Карточки отелей: тексты и ожидающие фотографии

Редакционные описания подготовлены без цен, ссылок бронирования, обещаний конкретного питания, оборудования номеров, расстояний до пляжа или доступности услуг. Тексты описывают позиционирование и настроение поездки; характеристики конкретного корпуса требуют проверки перед дальнейшим дополнением.

Скачивание с внешних сайтов отелей заблокировано: запросы к datatour.by, Google и сайтам отелей возвращают proxy CONNECT 403. Для LONICERA HOTELS назначен архивный снимок Lonicera World Resort из публичной медиатеки Datatour. Для REGNUM HOTELS назначена прямая ссылка Tourvisor, предоставленная пользователем; для остальных 23 карточек фото не назначены; стоковые и сгенерированные сцены не использованы. Домены отелей уже подтверждены в опубликованной пользователем конфигурации, однако текущий исполнитель по-прежнему получает 403. Дополнительная публикация тех же правил не требуется; для дальнейшей диагностики нужна новая сессия на опубликованной среде.

Для сетей нужно выбрать конкретный объект и подписать его на фото. Для SANDY BEACH, SAILORS HOTEL и MY LOME HOTEL при подборе фото дополнительно сверить точную идентичность объекта по исходному приоритетному списку. Не подставлять фото по одному совпадению названия.
